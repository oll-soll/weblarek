# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

### Данные
В приложении используются две сущности, которые описывают данные, - товар и покупатель.

**Товар** - это объект каталога, который содержит информацию о продукте, доступном для покупки.

```ts
interface IProduct {
  id: string;
  description: string;
  image: string;
  title: string;
  category: string;
  price: number | null;
}
```

**Описание полей interface IProduct**
- **id** - уникальный идентификатор
- **description** - описание товара
- **image** - ссылка на изображение товара
- **title** - название товара
- **category** - категория товара
- **price** - цена товара

**Покупатель** - это объект, который содержит в себе данные пользователя, необходимые для оформления заказа.

```ts
interface IBuyer {
  payment: TPayment;
  email: string;
  phone: string;
  address: string;
}
```

**Описание полей interface IBuyer**
- **payment** - выбранный способ оплаты (онлайн/при получении)
- **email** - электронная почта покупателя
- **phone** - номер телефона покупателя
- **address** - адрес доставки

### Модель данных
В приложении реализованы три основных класса, которые отвечают за хранение и обработку данных: каталог товаров, корзина и данные покупателя.

#### Класс CatalogModel (каталог товаров)
Класс отвечает за хранение списка всех товаров, работу с выбранным товаром для подробного просмотра и получения данных из каталога

Конструктор:  
`constructor()` - не принимает параметров, инициализирует внутренние структуры хранения данных.

Поля класса:  
`items: IProduct[]` - массив всех товаров каталога. Отвечает за хранение списка товаров, полученных с сервера.  
`preview: IProduct | null` - выбранный товар для подробного просмотра. Хранит текущий товар, который открыт в модальном окне.

Методы класса:  
`setItems(items: IProduct[]): void` - сохраняет массив товаров, полученного в параметрах метода.  
`getItems(): IProduct[]` - возвращает массив всех товаров из каталога.  
`getItemById(id: string): IProduct[] | undefined` - возвращает товар по его идентификтору.  
`setPreview(item: IProduct): void` - сохраняет товар для подробного отображения.  
`getPreview(): IProduct | null` - возвращает текущий выбранный товар.  

#### Класс BasketModel (корзина)
Класс отвечает за хранение товаров, которые добавлены пользователем в корзину.

Конструктор:  
`constructor()` - не принимает параметров, инициализирует пустую корзину.

Поля класса:  
`items: IProduct[]` - массив товаров в корзине, хранит все товары, добавленные пользователем для покупки.

Методы класса:  
`getItems(): IProduct[]` - возвращает массив товаров в корзине.  
`addItem(item: IProduct): void` - добавляет товар в корзину.  
`removeItem(id: string): void` - удаляет товар из корзины по его id.  
`clear(): void` - полностью очищает корзину.  
`getTotalPrice(): number` - возвращает стоимость всех товаров в корзине.  
`getCount(): number` - возвращает количество всех товаров в корзине.  
`hasItem(id: string): boolean` - проверяет наличие товара в корзине по его id.  

#### Класс BuyerModel (данные покупателя)
Класс отвечает за хранение и валидацию данных покупателя, которые необходимы для оформления заказа.

Конструктор:  
`constructor()` - не принимает параметров, инициализирует пустую модель данных покупателя.

Поля класса:  
`payment: TPayment | null` - способ оплаты.  
`address: string` - хранит адрес доставки, указанный пользователем.  
`phone: string` - хранит номер телефона, указанный пользователем.  
`email: string` - хранит адрес электронной почты, указанный пользователем.  

Методы класса:  
`setField(field: keyof BuyerModel, value: string | TPayment): void` - сохранение данных в модели без удаления остальных полей.  
`getData(): IBuyer` - возвращает все данные покупателя.  
`clear(): void` - очищает все данные покупателя.  
`validate(): Record<string, string>` - валидирует данные покупателя, возвращает объект с ошибками по полям.

### Слой коммуникации

#### Класс ApiClient
Класс отвечает за получение данных с сервера и отправку данных на сервер. При работе используется функциональность класса API, описанного выше.  

Конструктор:  
`constructor(api: IApi)` - принимает экземпляр класса API, через который выполняются запросы get и post.

Поля класса:  
`api: IApi` - экземпляр API класса, используемый для выполнения запросов к серверу.

Методы класса:  
`getProducts(): Promise<IProductsResponse>` - делает get запрос на эндпоинт /product/. Возвращает объект, в котором находится массив товаров.
`postOrder(data: IOrderRequest): Promise<IOrderResponse>` - делает POST запрос на эндпоинт /order/. Возвращает объект, подтверждающий покупку на определенную сумму.

### Слой View

#### Класс Header
Класс отвечает за отображение шапки главной страницы сайта, включая счетчик товаров в корзине и кнопку открытия корзины. Наследуется от Component.  

Конструктор:  
`constructor(container: HTMLElement, actions?: IHeaderActions)` - принимает ссылку на  DOM-элемент шапки и настраивает слушатель клика на кнопку корзины для генерации события, которое обрабатывается Презентером.

Поля класса:  
`counterElement: HTMLElement` - элемент для отображения текущего количества товаров в корзине.  
`basketButton: HTMLButtonElement` - кнопка корзины, открывающая модальное окно.  

Сеттеры класса:  
`set counter(value: number)` - устанавливает числовое значение счетчика товаров в counterElement.  

#### Класс Gallery
Класс отвечает за отображение каталога карточек товаров на главной странице. Наследуется от Component.  

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM-элемент контейнера галереи.  

Поля класса:  
`catalogElement: HTMLElement` - элемент-сетка, внутрь которого вставляются карточки товаров.  

Сеттеры класса:  
`set catalog(items: HTMLElement[])` - принимает массив готовых DOM-элементов карточек, очищает текущее содержимое catalog и вставляет новые элементы.  

#### Класс Modal
Отвечает за работу универсального модального окна-контейнера(открытие, закрытие, управление оверлеем икнопкой-крестиком). По требованию архитектуры не имеет дочерних классов - любой контент внутрь него передается динамически. Наследуется от Component.  

Конструктор:  
`constructor(container: HTMLElement, actions?: IModalActions)` - принимает ссылку на DOM-элемент модалки, находит кнопку закрытия и оверлей, настраивает на них слушатели событий для закрытия окна.  

Поля класса:  
`modalContent: HTMLElement` - элемент-контейнер для динамического размещения контента внутри модального окна.  
`modalButton: HTMLButtonElement` - кнопка-крестик для закрытия модального окна.  

Сеттеры класса:  
`set content(value: HTMLElement)` - принимает готовый DOM-элемент и вставляет его внутрь modalContent.  

Методы класса:  
`open(): void` - добавляет CSS-класс видимости модальному окну, отображая его на экране.  
`close(): void` - убирает CSS-класс видимости, скрывая окно, и очищает контент.  

#### Класс OrderSuccess
Отвечает за отображение модального окна, сообщающем об успешном оформлении заказа. Содержит информацию об общей стоимости товара и кнопку выхода из формы в каталог.  

Конструктор:  
`constructor(container: HTMLElement, actions?: IOrderSuccessActions)` - принимает ссылку на DOM-элемент модалки, настраивает слушатель клика на кнопку для закрытия окна и выхода в каталог товаров.  

Поля класса:  
`successButton: HTMLButtonElement` - элемент кнопки, закрывающий модалку.  
`successTotal: HTMLElement` - элемент для отображение общей стоимости товаров.  

Сеттеры класса:  
`set total(value: number)` - устанавливает числовое значение общей стоимости товаров.  

#### Класс Card
Отвечает за отображение карточки товара. Является общим базовым классом для всех типов карточек товара на сайте. Включает в себя отображение названия и стоимости товара, избавляя код от дублирования. Наследуется от Component.  

Конструктор:  
`constructor(container: HTMLElement, actions?: ICardActions)` - принимает ссылку на DOM-элемент контейнера карточки товара и необязательный объект с колбэками для обработки событий.  
Поля класса:  
`titleElement: HTMLElement` - элемент для отображения названия товара.  
`priceElement: HTMLElement` - элемент для отображения стоимости товара.  

Сеттеры класса:  
`set title(value: string)` - устанавливает строковое значение названия товара в карточке.  
`set price(value: number | null)` - устанавливает числовое значение стоимости товара в карточке. Если цена равна null, выводит текст "Бесценно".  

#### Класс CardItem
Наследуется от родительского класса Card. Отвечает за отображение карточки товара в каталоге на главной странице (работает с `<template id="card-catalog"`>). При клике генерирует событие для открытия детального просмотра.  

Конструктор:  
`constructor(container: HTMLElement, actions?: ICardItemActions)` - передает контейнер карточки в родительский класс и настраивает слушатель клика на весь контейнер-кнопку.  

Поля класса:  
`categoryElement: HTMLElement` - элемент для отображения категории товара в карточке.  
`imageElement: HTMLImageElement` - элемент для отображения изображения товара в карточке.  

Сеттеры класса:  
`set category(value: string)` - устанавливает строковое значение категории товара и может добавлять специфический CSS-класс для изменения цвета плашки в зависимости от названия категории.  
`set image(value: string)` - устанаваливает ссылку на иозображение товара в imageElement, используя улитарный метод родителя set image.  

#### Класс Preview
Наследуется от родительского класса Card. Отвечает за отображения карточки товара в детальном просмотре (работает с `<template id="card-preview"`>). Содержит подробное описание товара и кнопку, при клике по которой генерирует событие для добавления товара в корзину.  

Конструктор:  
`constructor(container: HTMLElement, actions?: ICardPreviewActions)` - передает контейнер родителю и вешает слушатель клика на кнопку.  

Поля класса:  
`imageElement: HTMLImageElement` - элемент для отображения изображения в карточке товара.  
`categoryElement: HTMLElement` - элемент для отображения категории товара.  
`textElement: HTMLElement` - элемент для отображения детального описания товара.  
`buttonPreview: HTMLButtonElement` - кнопка добавления товара в корзину. Меняет текст при клике.  

Сеттеры класса:  
`set image(value: string)` - устанаваливает ссылку на иозображение товара в imageElement, используя улитарный метод родителя set image.  
`set category(value: string)` - устанавливает строковое значение категории товара и может добавлять специфический CSS-класс для изменения цвета плашки в зависимости от названия категории.  
`set text(value: string)` - устанавливает строковое значение для детального описания товара в карточке.  
`set buttonText(value: string)` - изменяет текстовое значение элемента buttonPreview при клике (заменяет "Купить" на "Удалить из корзины").  

#### Класс BasketCard
Наследуется от родительского класса Card. Отвечает за отображение карточки товара в интерфейсе корзины (работает с `<template id="card-basket">`). Содержит кнопку удаления товара и его порядковый номер в списке корзины.  

Конструктор:  
`constructor(container: HTMLElement, actions?: IBasketCardActions)` - передает контейнер родителю и настраивает слушатель клика на кнопку удаления товара из корзины.

Поля класса:  
`indexElement: HTMLElement` - элемент для отображения порядкового номера карточки товара в списке корзины.  
`buttonDelete: HTMLButtonElement` - кнопка удаления элемента из списка товаров в корзине.  

Сеттеры класса:  
`set index(value: number)` - устанавливает числовое значение для текущего порядкового номера карточки товара в корзине.  

#### Класс Basket
Отвечает за отображение элемента корзины. Содержит список карточек товаров, общую стоимость заказа и кнопку с оформлением заказа, при клике по которой открывается форма оплаты и адреса доставки. Наследуется от Component.  

Конструктор:  
`constructor(container: HTMLElement, actions?: IBasketActions)` - принимает ссылку на DOM-элемент контейнера корзины и устаналивает слушатель клика на кнопку оформления заказа.  

Поля класса:  
`listElement: HTMLElement` - элемент для отображения списка товаров в корзине.  
`basketButton: HTMLButtonElement` - кнопка "Оформить" для перехода к заполнению данных об оплате и контактной информации.  
`priceElement: HTMLElement` - элемент для отображения полной стоимости всех товаров в корзине.  

Сеттеры класса:  
`set items(value: HTMLElement[])` - принимает массив DOM-элементов и добавляет их в корзину.  
`set total(value: number)` - устанавливает числовое значение для общей стоимости всех товаров в корзине.  

#### Класс Form
Базовый общий класс для отображение всех элементов-форм на странице. Включает в себя главную кнопку отправки данных и элемент для вывода ошибок валидации формы. Наследуется от Component.  

Конструктор:  
`constructor(container: HTMLElement, actions?: IFormActions)` - принимает ссылку на DOM-элемент контейнера формы. Настраивает слушатели submit и input на кнопку формы.  

Поля класса:  
`submitButton: HTMLButtonElement` - элемент для отображения кнопки формы.  
`errorsElement: HTMLElement` - элемент для отображения текста ошибок формы.  

Сеттеры класса:  
`set errors(value: string)` - принимает строковое значение для обозначения текста ошибок формы.  
`set valid(value: boolean)` - управляет доступностью кнопки отправки. Если value равно false, кнопка блокируется (добавляется атрибут disabled), если true - разблокируется.  

#### Класс Order  
Наследуется от Form. Отображает первый шаг в оформлении заказа - форму с выбором способа оплаты ("Онлайн" или "При получении") и полем для ввода адреса доставки. Работает с `<template id="order">`.

Конструктор:  
`constructor(container: HTMLElement, actions?: IOrderActions)` - передает контейнер в родительский класс и настраивает слушатели кликов на кнопки выбора оплаты.  

Поля класса:  
`cardButton: HTMLButtonElement` - кнопка выбора оплаты картой.  
`cashButton: HTMLButtonElement` - кнопка выбора оплаты при получении.  
`addressInput: HTMLInputElement` - элемент поля для ввода адреса доставки.  

Сеттеры класса:  
`set address(value: string)` - устанавливает текстовое значение в поле addressInput.  
`set payment(value: string | null)` - переключает активный CSS-класс (подсветку) между кнопками cardButton и cashButton в зависимости от выбранного способа оплаты.  

#### Класс Contacts  
Наследует от Form. Отвечает за отображение второго шага оформления заказа (работает с `<template id="contacts">`). Позволяет пользователю ввести адрес электронной почты и номер телефона.  

Конструктор:  
`constructor(container: HTMLElement, actions?: IContactsActions` - передает контейнер в родительский класс.  

Поля класса:  
`emailInput: HTMLInputElement` - элемент для отображения поля ввода электронной почты.  
`phoneInput: HTMLInputElement` - элемент для отображения поля ввода номера телефона.  

Сеттеры класса:  
`set email(value: string)` - устанавливает текстовое значение в поле emailInput.  
`set phone(value: string)` - устанавливает текстовое значение в поле phoneInput.  

### Логика событий приложения (Event Broker)
Связь между слоем представления (View) и моделями данных (Model) обеспечивается за счет событий, генерируемых через брокер событий (`EventEmitter`) в главном файле управления `index.ts`(Презентере).  

Ниже приведен список событий, разделенный по компонентам интерфейса, которые их инициируют в ответ на действия пользователя:  

#### 1. Компоненты главной старницы и карточек  
**Класс Header (Шапка сайта)**  
`onBasketOpen` - вызывается при клике на иконку корзины. Инициируется открытие модального окна с корзиной.  
**Класс CardItem (Карточка в каталоге)**  
`onItemOpen` - вызывается при клике на карточку товара в каталоге. Передает данные товара в Презентер для открытия окна предпросмотра (Preview).  
**Класс Preview (Окно предпросмотра товара)**  
`onButtonPreview` - вызывается при клике на кнопку "В корзину". Инициирует добавление товара в корзину и обновляет счетчик в шапке.  

#### 2. Компоненты модального окна  
**Класс Modal (Модальное окно)**  
`onModalClose` — генерируется в момент открытия любого модального окна. Используется для блокировки прокрутки основной страницы сайта.  

#### 3. Компоненты корзины  
**Класс BasketCard (Товар в корзине)**  
`onBasketDelete` - вызывается при клике на кнопку удаления (иконку корзины). Передает данные товара для его удаления из модели корзины.  
**Класс Basket**  
`onOrderAction` - вызывает при клике на кнопку "Оформить". Закрывает модалку корзины и открывает первый шаг оформления заказа (форма Order).  

#### 4. Компоненты форм оформления заказа  
**Класс Form**  
`onSubmit` - вызывается при отправке формы (нажатие кнопок «Далее» или «Оплатить»).  
**Класс Order (Форма выбора оплаты и адреса)**  
`onCardClick` - вызывается при выборе способа оплаты "Онлайн".  
`onCashClick:` - вызывается при выборе способа оплаты "При получении".
